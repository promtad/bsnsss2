# Binance Spot Signal Scanner (4h)

لوحة تحكم عربية لتحليل فرص Spot على Binance باستخدام شموع 4 ساعات. الأداة تعرض إشارات محتملة فقط ولا تنفذ أوامر تداول.

## المتطلبات
- Python 3.10 أو أحدث
- اتصال بالإنترنت
- لا تحتاج إلى API Key أو بيانات دخول

## التشغيل على Windows
1. فك ضغط الملف.
2. ثبّت Python من https://www.python.org/downloads/ إن لم يكن مثبتًا، مع تفعيل خيار Add Python to PATH.
3. انقر مرتين على `start_windows.bat`.
4. بعد التشغيل افتح رابط Streamlit المحلي الذي يظهر في نافذة الأوامر، غالبًا `http://localhost:8501`.

## التشغيل يدويًا
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## منطق الإشارة
- سوق Spot، أزواج USDT.
- اتجاه صاعد: Close > EMA20 > EMA50.
- RSI(14) بين 50 و68.
- اختراق إغلاق آخر شمعة مكتملة أعلى أعلى قمة للشموع العشرين السابقة.
- الدخول المرجعي هو إغلاق آخر شمعة مكتملة.
- ATR(14) يحدد وقف الخسارة والأهداف وفق المضاعفات المختارة في الشريط الجانبي.

## ملاحظات مهمة
- لا توجد أرباح مضمونة. هذه شروط فنية تجريبية وليست توصية مالية.
- لا توجد أوامر شراء أو بيع، ولا تُطلب مفاتيح API.
- جرّب الاستراتيجية تاريخيًا وتجريبيًا قبل اتخاذ قرارات حقيقية.
- إذا تعذر الاتصال بواجهة `data-api.binance.vision` بسبب الشبكة أو المنطقة، راجع التوثيق الرسمي أو جرّب شبكة مسموحًا بها.
- لا تفحص السوق بشكل متكرر جدًا؛ واجهة Binance تفرض حدودًا للطلبات.
